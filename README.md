# ExpenseTracker
This is a simple, self-contained Expense Tracker web app built with HTML, CSS, and JavaScript. It allows users to add expenses by name and amount, view a list with delete options, track a running total, and see the app output below.

Key Features

- Add Expenses: Form for entering name and amount with real-time validation.
- List & Delete: Dynamic list of expenses with individual delete buttons.
- Total Calculation: Automatically updates total spent, displayed prominently.
